## 一、总体说明

本研究的语料与财务数据均为**模拟生成（synthetic）**，由 `code/01_generate_corpus.py`
在固定随机种子（`RANDOM_SEED = 20260411`）下一次性生成，目的有二：

1. 真实年报全文受版权与 Wind / CSMAR / 巨潮 授权限制，无法随代码公开分发；
2. 用一个已知的潜在变量 `DT*` 作为"数据生成过程"，可以**反向校验**所构造的
   NLP 测度是否真的测到了目标构念（见 `table_reliability.csv` 最后一行的
   "与潜在真值相关"）。

数据生成过程的逻辑：

```
   企业数字化禀赋 + 年度趋势 + 噪声  →  DT*（潜在数字化程度）
                                          │
        ┌─────────────────────────────────┼──────────────────────────────┐
        ▼                                 ▼                              ▼
  数字化句抽样比例                 无形资产/技术岗占比               研发强度、专利产出
  → MD&A 模拟文本                  → 聚合效度参照                    → 预测效度与主回归因变量
```

## 二、文件清单与来源

### 2.1 `data/raw/`（原始数据）

| 文件 | 来源 | 说明 |
|---|---|---|
| `corpus_mda.csv` | **模拟生成** | 400 家公司 × 2018—2023 年，共 2400 条"管理层讨论与分析"文本。每篇由"数字化句"与"中性经营句"混合拼接而成，数字化句的抽样比例由 `DT*` 决定。 |
| `financial_panel.csv` | **模拟生成** | 与语料一一对应的企业-年度特征：行业、产权性质、公司规模、资产负债率、ROA、成长性、企业年龄、无形资产占比、技术岗人员占比、研发投入强度、专利申请数、第三方数字化指数（模拟）。另含 `dt_star_true`（潜在真值，**仅用于校验，不进入正式分析**）。 |

> 若要开展**真实**研究：把这两个文件替换为
> ① 巨潮资讯网 / Wind 下载的年报文本（提取 MD&A 章节）；
> ② CSMAR 下载的财务数据；
> 并保持列名一致（`firm_id, year, mda_text` 与财务字段），`02—06` 号脚本无需修改。

### 2.2 `data/interim/`（中间数据）

| 文件 | 由谁生成 | 处理步骤 |
|---|---|---|
| `user_dict.txt` | `02_preprocessing.py` | 把 60 个数字化转型词典词写入 jieba 用户词典，防止"数字化转型""工业互联网"等专有词被切碎。 |
| `corpus_clean.csv` | `02_preprocessing.py` | 对 `corpus_mda.csv` 依次执行：去页眉页脚/页码/证券代码噪声 → 统一标点 → jieba 精确模式分词 → 去停用词 → 词形归一。 |
| `corpus_tokens.json` | `02_preprocessing.py` | 保存分词结果（token 序列）与语料自动识别的"自定义停用词"列表，供 03、05 号脚本复用。 |
| `features.csv` | `03_feature_extraction.py` | 在分词结果上并行计算三条特征：词典法（计数/占比/两维度）、词嵌入（与"数字化语义轴"的余弦相似度）、LDA（主题比例、扩展词典占比）。 |

### 2.3 `data/processed/`（最终面板）

| 文件 | 由谁生成 | 说明 |
|---|---|---|
| `firm_year_panel.csv` | `04_measure_construction.py` | **最终企业-年份面板**，一行 = 一家公司一年。含 L1 原始计数（`Dict_Count`）、L2 标准化比率（`DT_Ratio` 为主测度）、L3 复合测度（`DT_Composite`）、主题比例法（`DT_LDA`）、词嵌入法（`DT_Embed`）以及全部控制变量；连续变量已在 1%/99% 分位缩尾。可直接导入 Stata / Python 做回归。 |

## 四、合规与留痕

| 事项 | 做法 |
|---|---|
| 来源标注 | 每个脚本文件头部注明输入/输出路径与数据来源 |
| 授权与频率 | 本仓库不抓取任何外部网站数据，故无 robots 与频率问题；真实数据须遵守数据库授权协议 |
| 样本口径 | 模拟数据统一为 400 家公司 6 年面板；真实研究须写明剔除规则（金融业、ST、缺失值等） |
| 去重与匹配 | `firm_id` 与 `year` 构成唯一主键，合并时用 `validate="1:1"` 强制校验 |
| 可复现 | 随机种子固定；词典、句库、停用词集中在 `code/nlp_utils.py`；每步中间产物落盘 |
